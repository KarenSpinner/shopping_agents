# Cases and customer messages

| File | Contents |
|---|---|
| `cases.json` | The 36 cases. Each has a company, a policy, the customer's request, and what the company's records show. |
| `messages.json` | The 216 customer messages, six for each case, plus the instruction given to the agent and the wording of each turn. |

Case ids end in `s` for a sound claim, `w` for a weak claim, and `c` for a clearly covered claim. `CU-01s` and `CU-01w` are a matched pair: same company, same policy, same small miss past the policy line, different reason.
